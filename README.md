# شركة الأيادي المتحدة — كتالوج المنتجات

موقع عربي متجاوب باستخدام Next.js وTypeScript وTailwind. يعرض 20 منتجًا مرتبة حسب النوع، مع بحث وتصنيفات وصور PNG شفافة قابلة للتكبير وطلب عبر WhatsApp.

## التشغيل على Windows

الإصدار الموصى به والمختبر Node.js 24.x وnpm.

```powershell
npm.cmd ci
npm.cmd run dev
```

افتح http://localhost:3000. للإنتاج:

```powershell
npm.cmd run build
npm.cmd start
```

## النشر

راجع `DEPLOYMENT.md` لنتيجة الفحص وإعدادات Vercel والملاحظة الأمنية المتبقية. أُضيف `vercel.json`، ولم يُنشر الموقع بعد.

هذه نسخة مصدر جاهزة للبناء على استضافة تدعم Next.js، وليست مجلد HTML جاهزًا للرفع على استضافة ثابتة.

للنشر عبر Vercel: ارفع ملفات المشروع إلى مستودع GitHub، ثم استورد المستودع كمشروع Next.js. مجلد المشروع هو الجذر، وأمر البناء `npm run build`. لا يحتاج الموقع متغيرات بيئة أو قاعدة بيانات في نسخته الحالية. لا ترفع node_modules أو .next أو المرفقات أو ملفات ZIP.

يمكن أيضًا نشره على خادم Node.js بتثبيت التبعيات وتشغيل بناء الإنتاج ثم npm start. تشغيل npm run dev مخصص للتطوير المحلي.

## تعديل البيانات

- `src/config/store.ts`: اسم الشركة والوصف والعملة ورقم WhatsApp. الرقم الحالي 9647749270990، بصيغة دولية دون + أو مسافات.
- `src/data/products.json`: المنتجات والأسعار والتصنيفات والتوفر والأوصاف ومسارات الصور.
- `src/types/product.ts`: تعريف TypeScript للمنتج.
- `public/products/clean/`: صور المنتجات PNG بخلفية شفافة. المسار داخل البيانات يبدأ بـ `/products/clean/`.
- `public/brand/logo.webp`: شعار الشركة.
- `public/hero/mascot.webp`: شخصية الواجهة الرئيسية.

السعر null يظهر «يُحدّد عند الاستفسار». التوفر true يتيح الطلب عند صحة رقم WhatsApp؛ false أو null يعطّل الطلب. المقاسات المختلفة لحفاضات سليبي تُطلب عبر WhatsApp؛ الصورة توضح المقاس 2 فقط.

روابط الطلب تفتح رسالة جاهزة تتضمن الاسم والمعرّف والسعر، مع encodeURIComponent؛ العميل يرسلها بنفسه. لا توجد لوحة إدارة أو حسابات أو دفع إلكتروني.

لتكبير صورة المنتج اضغط عليها؛ للإغلاق اضغط زر الإغلاق أو Escape. تدعم النافذة لوحة المفاتيح. تستجيب الواجهة للهاتف والكمبيوتر وتحترم إعداد تقليل الحركة.

## حفظ النسخة

نسخة ZIP داخل `releases/` تحتوي على المصدر والصور والإعدادات وpackage-lock.json، دون node_modules أو .next أو مرفقات المحادثة. فك الضغط ثم شغّل npm.cmd ci قبل البناء. الموقع لم يُنشر على الإنترنت بعد.
